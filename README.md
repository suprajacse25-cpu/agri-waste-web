# AGRI Waste Management System

A web demo of our hackathon idea: one farmer's waste is another farmer's resource.

**Live demo:** https://suprajacse25-cpu.github.io/agri-waste-management/

## The idea
Farmers often have agricultural waste they don't need, such as paddy straw, rice husk or coconut husk, while other farmers need exactly that waste. This system lets a farmer list the waste, and another farmer request and collect it, a bit like online shopping.

## What the demo does
- List waste with the farmer's name, place, type and quantity
- Search by place or farmer, and filter by type of waste
- Request a listing, mark it as collected, or cancel the request
- Live summary of listings, available, collected and kilograms listed

## Tech
HTML, CSS and JavaScript, deployed on GitHub Pages.

## Limits of this demo
Data is saved only in each visitor's own browser, so listings aren't shared between people. A real version would need a backend, a database, user accounts and a way for farmers to contact each other, which is the next step.
